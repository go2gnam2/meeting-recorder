# 회의록 레코더 — 홈페이지 배포 안내

이 폴더를 통째로 웹서버에 올리면 회의록 레코더가 **설치형 웹앱**으로 동작합니다.
휴대폰·PC에서 "앱 설치(홈 화면에 추가)"를 하면 아이콘이 생기고, 주소창 없이 앱처럼 열립니다.

## 폴더 구성
| 파일 | 역할 |
|---|---|
| `index.html` | 앱 본체 |
| `manifest.webmanifest` | 앱 이름·아이콘·색 정보 (설치에 필요) |
| `sw.js` | 앱 화면을 저장해 빠르게 열고, 인터넷이 끊겨도 녹음·기록 열람 가능 |
| `firebase-config.js` | 로그인 설정값. 비워 두면 로그인 없이 각 기기에서만 동작 |
| `firestore.rules` | 로그인·허가 보안 규칙(Firebase 콘솔에 붙여 넣는 용도, 서버에 올려도 무방) |
| `FIREBASE-설정안내.md` | 로그인 기능 켜는 방법(처음 한 번) |
| `icons/` | 앱 아이콘 |

## 올리는 방법
**꼭 https 주소여야 합니다.** http에서는 마이크 녹음과 앱 설치가 막힙니다.

1. **기관·개인 홈페이지 서버**: 폴더를 원하는 위치(예: `https://내도메인/meeting/`)에 그대로 업로드합니다. 하위 폴더에 두어도 됩니다.
   - 서버가 `.webmanifest`를 모르면 MIME 타입 `application/manifest+json`을 추가해 달라고 요청하세요(대부분은 설정 없이 됩니다).
2. **GitHub Pages(무료)**: 새 저장소에 이 폴더 내용을 올리고 Settings → Pages에서 공개합니다.
3. **Netlify Drop(무료, 가장 간단)**: app.netlify.com/drop 페이지에 이 폴더를 끌어다 놓으면 바로 주소가 생깁니다.

## 설치하는 방법
- **PC Chrome·Edge**: 주소창 오른쪽 설치 아이콘 또는 앱 상단의 "앱 설치" 버튼
- **안드로이드 Chrome**: 메뉴(⋮) → "앱 설치" 또는 "홈 화면에 추가"
- **iPhone·iPad Safari**: 공유 버튼 → "홈 화면에 추가"

## 로그인 (허가된 사람만 사용)
`FIREBASE-설정안내.md` 순서대로 Firebase를 설정하고 `firebase-config.js`를 채워 올리면, 로그인 화면이 생기고 관리자가 허가한 메일만 앱을 쓸 수 있습니다.
Google 계정 또는 이메일+비밀번호로 로그인하며, 회의 기록·요약·폴더는 계정에 저장되어 여러 기기에서 함께 보입니다.

## 알아 둘 점
- **녹음 파일과 API 키는 각 사용자의 기기에만** 저장됩니다. 오디오는 사용자가 고른 AI 회사(Gemini·OpenAI·Claude)로만 전송됩니다. 로그인을 켜면 기록·요약·폴더는 사용자 본인 계정(Firebase)에도 저장됩니다.
- **API 키는 사용자마다 각자 입력**합니다. 여러 명이 쓰면 각자 자기 키를 설정에 넣어야 합니다.
- **기기 간 동기화는 로그인을 켰을 때만** 됩니다. 로그인 없이 쓰면 PC에서 녹음한 회의는 휴대폰에 보이지 않습니다.
- **휴대폰 장시간 녹음**: 화면이 꺼지거나 다른 앱으로 넘어가면 iPhone은 녹음이 멈출 수 있습니다. 녹음 중에는 앱을 켜 둔 채로 두세요(앱이 화면 꺼짐 방지를 요청합니다). 3시간 회의는 PC나 노트북을 권장합니다.

## 업데이트할 때
새 `index.html`로 교체한 뒤 `sw.js` 맨 위의 `VERSION` 값을 바꿔 주세요(예: `mr-v7` → `mr-v8`). 사용자가 앱을 다시 열면 새 버전으로 바뀝니다.
